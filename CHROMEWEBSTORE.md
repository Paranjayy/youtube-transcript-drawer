## Store Listing

**Extension Name**
YouTube Auto-Transcript Drawer

**Short Description**
Automatically opens and displays a beautiful, interactive transcript panel on YouTube watch pages.

**Detailed Description**
YouTube Auto-Transcript Drawer is a sleek Chrome extension that automatically loads and displays the video transcript directly in a beautiful panel alongside the video.

Key Features:
- Automatically loads the transcript for any YouTube video you watch
- Centered auto-scrolling that highlights the current segment dynamically as the video plays
- Clickable timestamps that seamlessly jump the video player to that exact moment
- Real-time text search filter to quickly find specific words or phrases in the transcript
- Multi-language support to select any available caption track (including auto-generated ones)
- One-click copy transcript option to easily save the text to your clipboard
- Premium dark mode interface with smooth animations and layout integration

How to Use It:
1. Load this unpacked extension in your Chrome browser.
2. Open any video on YouTube.
3. The Auto-Transcript panel will automatically appear on the right sidebar.
4. Use the search bar to filter, click timestamps to jump around, or click copy to save the transcript.

Privacy and Permissions:
This extension runs completely client-side in your browser. It does not collect, store, or transmit any user data or browsing history off-device.
